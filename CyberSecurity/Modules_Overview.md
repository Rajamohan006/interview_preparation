# CyberSecurity Modules Overview

This document provides a concise description of each module contained in the `CyberSecurity` package.

| Module | Description |
|---|---|
| **Module-01-Introduction.md** | Introduction to cyber security, core concepts, CIA triad, goals, and basic terminology. |
| **Module-02-Terminologies.md** | Glossary of essential security terms and definitions. |
| **Module-03-Attacks.md** | Detailed overview of various attack vectors, malware, social engineering, and web attacks. |
| **Module-04-Cryptography.md** | Fundamentals of cryptographic algorithms, symmetric/asymmetric encryption, hashing, and PKI. |
| **Module-05-Authentication.md** | Authentication mechanisms, MFA, AAA, and identity management. |
| **Module-06-Governance.md** | Security policies, risk management frameworks, compliance standards. |
| **Module-07-Web-Security.md** | Web application security, OWASP Top 10, HTTP/S, cookies, and session protection. |
| **Module-08-Secure-Coding.md** | Secure coding practices, input validation, output encoding, and code review. |
| **Module-09-Vulnerability-Assessment.md** | Vulnerability lifecycle, scanning tools, and remediation strategies. |
| **Module-10-Penetration-Testing.md** | Pen‑testing methodology, reconnaissance, exploitation, and reporting. |
| **Module-11-Incident-Response.md** | Incident response process, playbooks, and mitigation techniques. |
| **Module-12-SOC-Operations.md** | Security Operations Center workflow, SIEM, log analysis, and monitoring. |
| **Module-13-Digital-Forensics.md** | Forensic fundamentals, evidence acquisition, chain of custody, and analysis. |
| **Module-14-Cloud-Security.md** | Cloud service models, security considerations for IaaS/PaaS/SaaS, and cloud architecture best practices. |
| **Module-15-Mobile-Security.md** | Mobile OS security, app reverse engineering, rooting/jailbreaking risks. |
| **Module-16-Reverse-Engineering.md** | Binary analysis basics, static/dynamic techniques, and tool chains. |
| **Module-17-APTs.md** | Advanced Persistent Threats, threat actors, TTPs, and ATT&CK framework. |
| **Module-18-Red-Teaming.md** | Red team tactics, adversary emulation, and blue‑team defenses. |
| **Module-19-Security-Architecture.md** | Designing secure enterprise architectures, Zero Trust, defense‑in‑depth. |
| **Module-20-Career-Paths.md** | Career trajectories, roles, certifications, and professional development. |
| **Module-21-Expert-Topics.md** | Advanced topics such as exploit development, buffer overflows, and modern defenses. |

Each module file contains in‑depth notes, diagrams, tables, and examples to support learning at beginner, intermediate, and expert levels.
