Module 20: Cyber Security Career Paths
### 20.1 Roles
Introduction to Cyber Security Career Paths
**Detailed Definition**

Cyber Security is a broad field containing multiple specialized career paths. Different roles focus on different areas such as monitoring attacks, securing applications, analyzing malware, responding to incidents, designing architectures, and hunting threats.

The objective of cyber security professionals is:

"Protect systems, applications, networks, and information against cyber threats."

Cyber security roles generally fall into:

```text
Defensive Roles (Blue Team)
          ↓
Offensive Roles (Red Team)
          ↓
Engineering Roles
          ↓
Research Roles
Cyber Security Career Hierarchy Example
SOC Analyst
      ↓
Security Analyst
      ↓
Security Engineer
      ↓
Security Architect
```
